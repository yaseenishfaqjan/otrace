# SEO / AEO / GEO records

This folder is the record of search, answer, and generative-engine work for https://otrace.co. It is not served as the public site.

Public files stay where the host must serve them:

| Public URL | Built from |
|---|---|
| `/llms.txt` | `seo/llms.txt`, copied to `site/public/llms.txt` by `site/scripts/sync-seo-public.mjs` during `npm run build`, then into `site/dist/public` by the prerender |
| `/robots.txt` | Written at prerender time by `robotsTxt()` in `site/scripts/seo-public.mjs`. `seo/robots.txt` is the mirror for `https://otrace.co` |
| `/<indexnow-key>.txt` | Written into `site/public/` by the same sync. The key constant is in `api/indexnow.js`. See `indexnow.md` |

## What lives here

- `SEO-LOG.md` — one appended entry per brief task. Do not rewrite old entries.
- `llms.txt` — source of the public `/llms.txt`.
- `robots.txt` — mirror of the production robots file. Regenerated by the sync script.
- `query-research.md` — Google Autocomplete results and the collision decisions.
- `entities.md` — the names and numbers the public copy is supposed to repeat.
- `indexnow.md` — where the key file lives and how submission runs. The key is public ownership proof.
- `verify.mjs` — checks that can fail. Run `node seo/verify.mjs` for the self-test, and `node seo/verify.mjs --root site/dist/public` after a build.
- `shots/` — screenshots of the local prerender, not of the live site.
- `checks/` — saved command output, including the live site before this change was deployed.

`dist/` is gitignored. A green build is not a live deploy.
